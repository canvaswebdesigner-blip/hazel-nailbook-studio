# Hazel Nailbook Studio

Güzellik ve tırnak stüdyoları için tasarlanmış, hizmetleri güven veren bir anlatımla sunan ve ziyaretçiyi randevuya yönlendiren çok sayfalı web deneyimi.

## Öne çıkanlar

- Hizmet detay sayfaları ve çalışma galerisi
- Hakkımda, hijyen, iletişim ve sık sorulan sorular bölümleri
- Randevu akışı ile randevu ve iptal koşulları
- Gizlilik ve kullanım koşulları sayfaları
- Mobil öncelikli, erişilebilir ve tutarlı arayüz

## Teknoloji

- React 19
- TypeScript
- TanStack Start
- Tailwind CSS
- Radix UI

Bu depo, yerel bir güzellik işletmesi için hazırlanmış portföy çalışmasını içerir.
